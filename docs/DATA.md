# 데이터 준비

원천 매입·매출 파일은 제공 폴더에 없으며 이 저장소에도 포함하지 않았습니다. 대회에서 받은 자료는 이용 조건을 확인한 뒤 본인 환경에서 준비하세요.

## 보고서의 활용 자료

- A·B 물류센터 매입 및 매출 자료: 2021~2024년
- 상품정보: 가공식품 및 신선식품
- 서울시 월 평균기온, 월 누적강수량, 소비자물가지수
- 공휴일 캘린더

## 노트북 입력

| 노트북 | 필요한 입력 | 주요 열 |
|---|---|---|
| 01 | A센터 생수·음료·건강 월별판매수량 CSV | 연월, 판매수량 |
| 01 | A센터 신선식품 전처리 CSV | 연월, 판매수량 |
| 01 | 기온 CSV, 공휴일 캘린더 CSV | 년월, 평균기온, 평균최고기온 및 휴일 관련 열; 원본 셀 참조 |
| 02 | B센터 봉지라면·탄산음료 전처리 CSV | 판매일, 판매수량 |
| 03 | A센터 신선식품 전처리 CSV | 판매일, 구분, 판매수량, 상품명 등 |
| 03 | 기온, 강수량, 소비자물가지수 CSV | 파일별 날짜 및 해당 지표 열; 원본 셀 참조 |

01·02 노트북의 원래 읽기 위치는 `./수요예측부문 데이터 제공/csv파일 모음/`입니다. 03은 Colab의 `/content/drive/MyDrive/프로젝트/유통_수요예측/`를 사용합니다. 파일별 인코딩과 열 이름이 달라 각 읽기 셀을 확인해야 합니다.

## 결과 해석

리드타임과 발주주기는 실제 발주일 기록이 없어 매입·매출 패턴으로 추정한 값입니다. 서비스 수준, 안전재고율과 초기재고를 정해 매입량을 계산했으며, 실제 운영에서 비용이 얼마나 줄었는지를 측정한 값은 아닙니다. 보고서 11쪽의 예측 수량도 실제 판매 실적과 구분합니다.
