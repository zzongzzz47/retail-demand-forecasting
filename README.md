# 품목별 수요예측과 매입량 산정

**제4회 유통데이터 활용 경진대회 · 수요예측 부문 · Nexus 팀**

물류센터에서 얼마나 팔릴지 예측한 뒤, 그만큼을 바로 매입해도 될까? 재고와 입고 대기 물량, 상품의 수요 변동까지 고려해 매입량을 정하는 과정을 분석했습니다.

**[분석 보고서](reports/nexus_demand_forecasting_report.pdf) · [사용한 코드](code/) · [결과표](results/) · [데이터 준비](docs/DATA.md)**

## 어떤 문제를 다뤘나

음료와 신선식품은 판매량이 늘어나는 시기가 있고, 봉지라면은 다른 변동 양상을 보였습니다. 모든 품목에 같은 예측 방법과 안전재고 비율을 적용하기보다, 품목별로 모형을 비교하고 매입량을 산정했습니다.

| 구분 | 분석 범위 |
|---|---|
| 자료 | A·B 물류센터의 2021~2024년 매입·매출 및 상품정보 |
| 품목군 | A센터 생수·음료·건강, 신선식품 / B센터 탄산음료, 봉지라면 |
| 예측 대상 | 2025년 1~3월 판매수량 |
| 검증 | 학습 기간을 늘려 가며 3개월씩 예측하는 롤링 검증 |
| 연결한 의사결정 | 안전재고, 재고 상태와 입고 예정량을 반영한 매입량 산정 |

## 분석 과정

1. 매입·매출과 상품정보를 정리하고 품목군별 월 판매수량 구성
2. 계절성과 변동을 살펴본 뒤 Naive, SARIMA 계열, Prophet 등 비교
3. 품목군별 검증 RMSE를 기준으로 모형 선정
4. 예측 판매량에 리드타임, 발주주기와 안전재고를 반영해 일별 재고 흐름 계산
5. 입고 시점을 기준으로 월별 매입량 집계

## 보고서에 기록된 결과

| 품목군 | 선정 모형 | 검증 RMSE |
|---|---|---:|
| A센터 생수·음료·건강 | Prophet | 2,607.00 |
| A센터 신선식품 | SARIMA | 492.11 |
| B센터 탄산음료 | Prophet | 2,607.00 |
| B센터 봉지라면 | Prophet | 291.37 |

출처: 제출 보고서 6쪽 표 2. RMSE는 낮을수록 좋으며, 판매 규모가 다른 품목끼리 절댓값을 직접 비교하지 않습니다. 수치는 원 보고서에서 옮겼고 이번 정리 과정에서 다시 학습한 결과는 아닙니다.

신선식품에서는 Prophet보다 SARIMA의 오차가 작았습니다. 예측 모형을 품목별로 선택하고, 그 결과를 안전재고와 매입 계획에 연결한 것이 이 프로젝트의 핵심입니다. 재고 비용 절감액이나 현장 품절 감소율을 실측한 프로젝트는 아닙니다.

## 실행 범위

이 저장소는 **제공된 코드와 보고서를 정리한 분석 기록**입니다. 원천 데이터가 포함되어 있지 않아 내려받은 상태에서 전체 분석이 바로 실행되지는 않습니다. 보고서에 사용된 Prophet 최종 실험과 매입량 시뮬레이션 코드도 이번 제공 폴더에는 없습니다. 현재 노트북의 역할과 경로 설정은 [실행 안내](code/README.md)에 정리했습니다.

노트북의 계산 코드와 설명은 유지하고 저장된 출력만 제거했습니다. `modeling2 (1).ipynb`는 `modeling2.ipynb`와 파일 내용이 같아 한 번만 수록했습니다. 팀 결과물이며, 개인별 역할이나 수상 여부는 별도로 기재하지 않았습니다.
